# Dicionário de dados

- `nino34`: anomalia da região Niño 3.4.
- `oni`: Oceanic Niño Index.
- `prob_el_nino`: probabilidade simulada/referencial de El Niño.
- `chuva_7d_mm`, `chuva_15d_mm`, `chuva_30d_mm`: chuva acumulada.
- `anomalia_temp_c`: temperatura acima ou abaixo da média.
- `umidade_solo_pct`: leitura simulada do ESP32.
- `ndvi_atual`: índice vegetativo simulado.
- `irea_indice_risco_enso_agricola`: índice próprio do projeto, de 0 a 100.
- `risco_produtivo`: baixo, moderado, alto ou crítico.
- `risco_comercial`: risco gerado pela combinação entre produção revisada e percentual vendido.
- `risco_entrega_sc`: volume potencialmente descoberto caso a produção revisada fique abaixo do volume vendido.
